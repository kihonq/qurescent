The reader renders the Madani mushaf with **QCF V4 tajweed fonts**. Colors are
inside the glyphs (same approach as Quran.com), not painted with CSS after
layout.

Open **Settings** on a surah page: switches for word-by-word and colored
tajweed, plus a single translation ([EN] / [MS]). Colored tajweed uses QCF V4
COLRv1 with a dark `font-palette` in dark mode (Firefox uses OT-SVG theme
packs).

:::note[Draft — spot-check pending]
Swatches below are **exact hexes from QCF V4 COLRv1 `CPAL` palette 0** (light theme) in the self-hosted
fonts. Rule names follow the published **Dar Al-Maarifah** Mus’haf al-Tajweed legend (Al-Azhar Islamic
Research Academy endorsement, 1999). Quran.com/QF are widely reported to model that system, but that
claim is not an official QF spec — treat this page as a **working draft** until you spot-check against
a physical Dar Al-Maarifah–style mushaf (wayfinder [#2](https://github.com/kihonq/qurescent/issues/2)).
:::

Colors live **inside** the glyphs (`font-palette` bases 0/1/2 for light/dark/sepia). They cannot be
patched in CSS. Dark/sepia palettes retint the same slots for theme contrast; the table uses the light
palette as the reference.

## How this was derived

1. **Hexes** — dumped from `public/fonts/qcf-v4/colrv1/p*.woff2` `CPAL` palette 0 (identical across sampled pages).
2. **Rule names** — Dar Al-Maarifah published legend ([Tajweed Quran Colors Roles](https://easyquran.com/en/tajweed-quran-colors-roles/)).
3. **Slot → family** — matched by DAM’s color families (reds / green / blues / gray), not by an official QCF index table (QF docs only cover how to *apply* palettes, not what each slot means).

Repo research trail: `docs/research/tajwid-color-standard.md`.

## Spot-check checklist

When reviewing against a physical mushaf, verify a few known cases on `/read/` with **colored tajweed** on:

- [ ] Madd lāzim vs wājib vs jāʾiz vs ṭabīʿī (four red/gold shades stay distinct)
- [ ] Green on ikhfāʾ / iqlāb / mushaddad nūn-mīm
- [ ] Light blue on qalqalah letters with sukūn
- [ ] Dark blue on tafkhīm rāʾ
- [ ] Gray on silent / assimilated letters
- [ ] Whether CPAL 10–12 ever mark a real rule you care about naming
