The reader renders the Madani mushaf with **QCF V4 tajweed fonts**. Colors are
inside the glyphs (same approach as Quran.com), not painted with CSS after
layout.

## What is here

- [Color legend](/guide/tajwid/color-legend/) — draft color → rule table from QCF `CPAL`
  hexes + Dar Al-Maarifah labels (spot-check still required before treating it as signed-off)

Open **Settings** on a surah page: switches for word-by-word and colored
tajweed, plus a single translation ([EN] / [MS]). Colored tajweed uses QCF V4
COLRv1 with a dark `font-palette` in dark mode (Firefox uses OT-SVG theme
packs).
