Qurescent is a **static** techdoc for learning the Quran: Starlight guides plus a
Madani mushaf under [/read/](/read/). Sedekah jariah — non-commercial, ads-free.
No runtime Quran APIs; verse and tajwid correctness are treated as zero-tolerance.

**Alpha:** [v0.1.0-alpha.0](https://github.com/kihonq/qurescent/releases/tag/v0.1.0-alpha.0) ·
source on [GitHub](https://github.com/kihonq/qurescent).

## Credits

### QCF V4 tajweed fonts

Mushaf glyphs are rendered with the **Quran Complex Font (QCF) V4** tajweed color
fonts (COLRv1).

Font binaries are **not** shipped in the Git repository (`bun run data:fonts` downloads
them locally). They are **not** covered by this project’s MIT license — see
[`NOTICE`](https://github.com/kihonq/qurescent/blob/main/NOTICE) in the repo.

### Data & other sources

Chapter metadata, word-by-word glosses, and translations are ingested once into
`src/data/`. Named sources and licenses: [`SOURCES.md`](https://github.com/kihonq/qurescent/blob/main/src/data/SOURCES.md).

Tajwid **color names** on the [color legend](/guide/tajwid/color-legend/) follow the
published Dar Al-Maarifah Mus’haf al-Tajweed system (draft; spot-check still open).

### Stack

Astro, Starlight, React, Bun, Cloudflare Pages — and the usual open-source
dependencies listed in `package.json`.
